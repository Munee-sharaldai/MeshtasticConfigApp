# Развертывание
1) Склонировать репозиторий.
2) Перейти в корень репозитория.
3) Создать файл ".env" и скопировать в негр содержимое файла ".env.example".
4) Скачать [Nmap](https://nmap.org/download#windows).
5) Задать значение "full\\path\\to\\Nmap" переменной NMAP_PATH.
6) Скачать Python версии 3.12.7, если не скачан.
7) Создать окружение командой: "python -m venv ./venv".
8) Активировать окружение командрой: "./venv/Scripts/activate".
9) Установить зависимости командой: "pip install -r ./requirements.txt".
10) Запустить проект командой: "python ./app.py".
11) Проект доступен по адресу: "http://localhost:8000/".
# Развертывание на бесплатном хостинге
1) Скачайте [nginx](https://nginx.org/en/download.html).
2) Откройте терминал в папке с установленным nginx.
3) Запустите nginx командой: "nginx".
4) Откройте новой окно терминала.
5) Создайте ssh-ключ командой: "ssh-keygen -t ed25519 -C "localhost.run" -f C:\Users\<имя_пользователя>\.ssh\<название_файла_ключа>".
6) Откройте файл "C:\Users\<имя_пользователя>\.ssh\<название_файла_ключа>.pub" и скопируйте его содержимое.
7) Откройте сайт "admin.localhost.run", зарегистрируйтесь и добавьте созданный ssh-ключ (вставить скопированное содержимой ключа).
9) Вернитесь в терминал и активируйте хостинг командой: "ssh -i C:\Users\<имя_пользователя>\.ssh\<название_файла_ключа> -R 80:127.0.0.1:8000 localhost.run".
10) Проект доступен по выведенному предудыщей командой адресу.
